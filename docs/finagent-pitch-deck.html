Hackathon • B2B KYC

FinAgent

Agen AI untuk KYC & Due Diligence: dokumen perusahaan diubah menjadi knowledge graph, lalu diinterogasi dengan bahasa alami — dengan paywall pembayaran nyata (DOKU) yang menjadi bagian dari alur agen (LangGraph).

LangGraph • GPT-4o • Neo4j Aura DOKU Payment Gateway
Masalah

Mengapa ini penting?

Due diligence tradisional bergantung pada membaca manual dan spreadsheet. Hubungan pemilik manfaat, direksi, dan afiliasi sulit dilacak secara konsisten dari banyak dokumen.

  • Fragmentasi data: fakta tersebar di akta, laporan, dan lampiran PDF.
  • Risiko terlewat: pola kepemilikan silang atau entitas sekutu tidak terlihat tanpa model relasi.
  • Skalabilitas: tiap kasus baru memakan waktu analis senior.
  • Nilai bisnis: analisis mendalam layak dibayar — tetapi harus terintegrasi ke sistem, bukan sekadar tombol manual.
Solusi

FinAgent dalam satu kalimat

Mengubah dokumen menjadi graf yang bisa ditanya seperti analis senior — dengan agen yang memutuskan langkah, memanggil Neo4j, dan mengunci investigasi premium di belakang pembayaran DOKU yang sah secara teknis.

Differentiator

Paywall di dalam workflow agen

Bukan sekadar popup frontend: node payment_gatekeeper di LangGraph menghentikan alur sampai status bayar terverifikasi lewat webhook server-to-server DOKU — cocok untuk kriteria hackathon (reasoning + tools + payment).

User bertanya (investigasi dalam) │ ▼ ┌─────────────────────┐ │ payment_gatekeeper │──── tidak bayar ───► kirim link DOKU + invoice └─────────┬───────────┘ │ bayar OK (webhook) ▼ planning → write_query → run_query(Neo4j) → answer_user
  • notification_url mengarah ke endpoint publik aplikasi (deploy / tunnel).
  • Sesi persisten (file / storage) agar webhook tetap konsisten setelah restart.
Roadmap

Status & langkah berikutnya

  • Sudah ada: ekstraksi entitas & relasi, resolusi entitas (fuzzy), visualisasi graf (vis.js), trace node di chat, ekspor laporan HTML.
  • Deploy: Hugging Face Spaces (Docker), dengan secrets Neo4j / LLM / DOKU / APP_BASE_URL.
  • Next: RBAC multi-penyewa, audit trail formal, pemeringkatan risiko skor, dan konektor dokumen tambahan.
